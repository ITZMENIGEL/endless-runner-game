# Endless Runner Game

A fast-paced endless runner game built with Unity, inspired by Subway Surfers.

## Features

- **Endless Gameplay**: Navigate through infinite procedurally generated levels
- **Dynamic Obstacles**: Avoid various obstacles and collect power-ups
- **Score System**: Compete for high scores with a persistent leaderboard
- **Mobile-Optimized**: Touch controls for seamless mobile gameplay
- **Visual Polish**: Smooth animations and engaging particle effects

## Getting Started

1. Clone the repository
2. Open with Unity (2021 LTS or higher recommended)
3. Load the `Main` scene from `Assets/Scenes/`
4. Press Play to start developing

## Controls

- **Left/Right Arrow** or **A/D**: Move left/right
- **Touch Swipe**: Move on mobile devices
- **Space**: Jump (if implemented)
